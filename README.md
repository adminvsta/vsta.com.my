# VSTA Solutions — One-page website

A responsive, static company website for VSTA Solutions Sdn. Bhd. It is ready for GitHub Pages and does not require a build step.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload everything in this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Add `vsta.com.my` under **Custom domain** after the GitHub Pages URL is live.

The included `.nojekyll` file ensures GitHub serves the site exactly as provided.

## Domain DNS

Follow the current GitHub Pages custom-domain instructions when connecting `vsta.com.my`. DNS values can change, so confirm them in GitHub’s documentation before updating the domain.

## Files

- `index.html` — complete one-page site
- `styles.css` — responsive design and layout
- `script.js` — mobile navigation and scroll reveal
- `assets/` — hero and VSTA sock product imagery
